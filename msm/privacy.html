개인정보처리방침

MOGRINO Studio Manager · 시행일: 2026년 11월 24일

본 방침은 MOGRINO Studio Manager(이하 MSM)의 Google API 데이터 처리에 적용됩니다. MSM은 MOGRINO Studio의 운영자 전용 관리 도구이며, 게임 자체의 개인정보처리방침과는 별개입니다.

1. 접근하는 데이터

  • Google Analytics Data API: 날짜 및 기간별 활성·신규 이용자 수, 세션, 참여 시간, 국가 코드, 앱 버전 및 코호트 잔존율 등 집계된 보고서.
  • Google Sheets 및 Drive: 운영 전용 파일의 식별자, 파일·시트 정보, 설정, 보고서, 실행 이력 및 오류 기록 등 운영에 필요한 데이터.
  • Google OAuth: 운영자의 Google 계정 권한 승인 및 승인 상태. MSM은 Google 계정 비밀번호를 직접 수집하지 않습니다.
  • 문의 이메일: 운영 관련 문의나 삭제 요청을 직접 보내는 경우 발신 주소와 문의 내용.

현재 Analytics 수집기는 개별 게임 이용자의 이름, 이메일, 광고 식별자 또는 원시 이벤트 기록을 조회하도록 설계되어 있지 않습니다. Google 서비스에 부여된 권한의 범위와 별개로 실제 사용은 위 운영 기능에 필요한 데이터로 제한합니다.

2. 이용 목적

게임 성과 분석, 운영용 보고서 생성·갱신, 데이터 수집 상태 확인, 오류 해결 및 운영 파일 관리를 위해 사용합니다. Google API 데이터를 판매하거나 광고 타기팅, 신용 평가 또는 범용 AI 모델 학습에 사용하지 않습니다.

3. 저장 및 보호

수집한 보고서와 기록은 운영자의 접근 권한으로 보호되는 Google Sheets와 Google Drive에 저장하며 Google Apps Script에서 처리합니다. 운영 파일은 공개 공유하지 않으며, Google 인증 정보나 내부 데이터는 공개 안내 사이트에 게시하지 않습니다. 운영에 필요한 기간 동안 보관하고 목적이 종료되거나 삭제 요청이 처리되면 불필요한 데이터를 삭제합니다. 운영 백업에 포함된 데이터 역시 삭제 대상 여부를 확인하여 처리합니다.

4. 공유 및 제3자 제공

MSM은 Google API 데이터를 제3자에게 판매하거나 별도 목적으로 제공하지 않습니다. Google은 인증·보고서 조회·저장 및 실행에 필요한 서비스 제공자이며, 공개 안내 페이지는 GitHub Pages에서 호스팅됩니다. 법적 의무 준수 또는 보안 사고 대응 등 관계 법령 및 Google 정책이 허용하는 경우에 한해 필요한 범위에서 정보를 처리할 수 있습니다.

5. 권한 철회와 데이터 삭제

운영자는 Google 계정의 연결 관리에서 MSM의 권한을 철회할 수 있습니다. 권한 철회는 이후 API 접근을 차단하지만 이미 저장된 운영 파일의 데이터를 자동으로 삭제하지는 않습니다. 저장 데이터의 열람·정정·삭제에 관한 요청은 아래 이메일로 접수하고, 요청의 권한과 범위를 확인하여 처리합니다.

6. Google 데이터 정책

MSM은 Google API Services User Data Policy 및 적용되는 Limited Use(제한된 사용) 요구사항을 준수합니다. Google API에서 받은 데이터와 그로부터 파생된 정보는 본 방침에 명시한 운영 기능에 필요한 범위에서만 사용합니다.

7. 공개 페이지 및 향후 변경

이 안내 페이지에는 자체 분석 스크립트, 광고, 로그인 양식 또는 추적 쿠키를 설치하지 않았습니다. 호스팅 서비스는 접속에 필요한 기술적 정보를 자체 정책에 따라 처리할 수 있습니다. 향후 AdMob 또는 Google Play API를 연동하거나 처리 목적이 변경되면 실제 변경 사항을 반영하여 본 방침을 갱신합니다.

Privacy Policy

Effective November 24, 2026. This policy applies to MOGRINO Studio Manager (MSM), a private tool for the authorized MOGRINO Studio operator, not to the games themselves.

Data accessed

MSM reads aggregate Google Analytics reports (active and new users, sessions, engagement duration, countries, app versions and cohort retention). It accesses operational file and sheet metadata, configurations, reports, run logs and error logs in Google Drive and Sheets. Google OAuth manages the operator's authorization; MSM does not directly collect Google account passwords. Emails sent to the contact address may contain the sender's address and message. The current Analytics collector is not designed to retrieve individual player names, email addresses, advertising identifiers or raw event records.

Use, storage and protection

Data is used to analyze game performance, maintain operational reports and files, monitor collection and resolve errors. Reports and records are processed by Google Apps Script and stored in access-controlled Google Sheets and Drive files, not publicly shared. MSM does not sell Google API data or use it for ad targeting, credit assessment or training general-purpose AI models. Data is kept as needed for operations; unnecessary records are deleted when no longer required or when an authorized deletion request is fulfilled, including assessment of applicable backups.

Sharing

Google provides authorization, reporting, processing and storage services. GitHub Pages hosts this public informational site. MSM does not provide Google API data to third parties for independent purposes. Disclosure may occur only as necessary for legal obligations or security response, as allowed by applicable law and Google policy.

Authorization and deletion

The operator can revoke access through Google Account connections. Revocation blocks subsequent API access but does not automatically erase previously stored data. Contact mogeulino@gmail.com to request access, correction or deletion; requests are handled after confirming authorization and scope.

Limited Use

MSM’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including applicable Limited Use requirements. Google API data and derived information are used only for the operational features described in this policy.

Public site and updates

These informational pages do not install analytics scripts, ads, login forms or tracking cookies. Hosting providers may process technical access information under their own policies. This policy will be updated before material changes in data use, including future AdMob or Google Play integrations. Contact: MOGRINO Studio, mogeulino@gmail.com.

해당 데이터는 게임 운영 및 광고 성과 분석을 목적으로 사용하며, 접근이 제한된 운영 전용 Google Sheets 및 Drive에 저장합니다.

MSM은 광고 설정, 지급 계좌 및 결제 정보를 변경하지 않습니다. 수집한 데이터를 판매하거나 광고 타기팅 목적으로 이용하지 않습니다. 데이터 공유, 보호 및 삭제에는 본 방침의 기존 조항이 적용됩니다.

AdMob Data Processing

Updated: November 24, 2026

MSM requests read-only access to the Google AdMob API for internal advertising performance and revenue analysis.

Data may include publisher account identifiers, app and ad unit information, ad requests, matched requests, impressions, clicks, estimated earnings, reporting time zones, and currencies.

Data is stored in access-restricted Google Sheets and Drive files for internal game operations. MSM does not modify advertising settings, payment accounts, or billing information. Google API data is not sold or used for advertising targeting.

Existing provisions regarding data sharing, protection, retention, and deletion apply.
